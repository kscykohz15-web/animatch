# 文体・構成規約 — ゆるオタの部屋

既存10記事から抽出した実物ベースの規約。記事を書く前に必ず読むこと。
ここに書かれていないことは既存記事に合わせる。迷ったら既存記事を読み直す。

## 基本

- **です・ます調**
- **一人称は「私」**。運営者は YouTube で「かさ【ゆるオタ】」を名乗る
- 1段落は**1〜3文**。長い段落は作らない
- 漢字を開く: 「事」→「こと」、「出来る」→「できる」、「頂く」→「いただく」

## 声のつくり方

既存記事の強みは**実際に見た人間の言葉**であること。ここを失うと量産記事と区別がつかなくなる。

### 必ず入れるもの

**体験として語る一文を各記事に最低3箇所。** 実例（既存記事より）:

- 「後半に差し掛かってからは、続きが気になりすぎて、見始めたらいつの間にか朝になってしまってました」
- 「その考え抜かれたストーリー構成と伏線回収には思わず鳥肌が立ちました」

作品の説明ではなく、**見たときに自分がどうなったか**を書く。

**不都合な事実も正直に書く。** 実例:

- 「おおよそ主要のサイトでは視聴できますが、Prime Videoでは視聴できないので注意です」
- 「前半部分は動きのない展開が多く、ちょっと変わった日常モノといった内容で退屈と感じる方もいらっしゃると思います」

弱点を隠さないことが信頼になり、そのうえでの推薦が効く。欠点を書いたら、
必ずそれを上回る理由をセットで書く（「騙されたと思って後半部分まで見続けていただきたい」）。

**読者への語りかけを各記事に1〜2箇所。**
「〜していただきたい作品です」「〜な方は絶対ハマると思います」

### 断定の強弱

- 事実（放送年・話数・配信先）は**言い切る**。裏が取れていないなら書かない
- 評価・感想は**柔らかく**: 「〜だと思います」「個人的には〜」「〜な方には刺さるはずです」
- 事実を感想の語尾でぼかすのは禁止。「2021年放送とされています」のような書き方はしない。
  裏が取れたなら「2021年放送です」、取れないなら削除

## 禁止事項

- **ネタバレの無警告記載**。終盤の展開は「後半の怒涛の展開」のように抽象化する。
  どうしても必要なら見出し直後に警告を置く
- **未確認の事実**。放送年、話数、配信先、声優、原作、制作会社、受賞歴
- **他サイトの文章の流用**。あらすじも自分の言葉で書き直す
- **過剰な煽り**。「神」「最強」はタイトルの定型表現としては可、本文の連発は不可
- **性的な内容**。AdSense の規約違反となりサイト全体の広告が停止するリスクがある

## 構成

### list（まとめ記事・動画連動）

```
導入（2〜3文。フック＋動画の存在に触れる）
[YouTube 動画の埋め込み]
H2 <テーマ>アニメ<N>選
   H3 作品名  ×N
       基本情報（放送年 / 話数 / 制作 / 原作）
       あらすじ（2〜3文、ネタバレなし）
       推しポイント（体験として語る、2〜4文）
       配信先（確認日を明記）
H2 おすすめの動画配信サービス
   比較表 ＋ アフィリエイト枠
まとめ（1〜2文）＋ 参照元
```

### vod_guide（作品単体）

```
導入1文（フック）
H2 「作品名」が見れる動画配信サービス(アプリ・サブスク)まとめ
   H3 現在配信されているサービス一覧
   H3 配信が確認できなかったサービス一覧
   （一覧の後に一言コメント。見られないサービスがあれば必ず明記）
H2 作品情報とあらすじ
   H3 作品情報 / H3 あらすじ
H2 見どころと個人的おすすめポイント
   H3 見どころ ×2
H2 「作品名」と似ている作品
   H3 ジャンル別
H2 アニメ見放題におすすめのサブスク
```

## タイトル

- **32文字前後**。既存記事（60文字超）は検索結果で切れているため踏襲しない
- **主キーワードを前方に**
- 定型の【】プレフィックスは踏襲してよい（【一気見】【感動】【名作】など）
- 動画連動記事は動画タイトルをベースに、検索キーワードを意識して調整する

## スラッグ

**英数小文字とハイフンのみ。** 既存記事は日本語スラッグだが踏襲しない。

例: `anime-time-melts-20`, `isekai-anime-15`, `steins-gate-vod`

## 配信情報の扱い

配信先は頻繁に変わる。以下を必ず守る。

- 記事内に**確認日**を明記する（例: 「2026年11月18日時点」）
- 「最新の配信状況は各公式サイトでご確認ください」を添える
- **配信していないサービスも明記する**。既存記事の強み

## 収益リンク

**重要**: 既存記事の VOD リンクの大半は報酬が発生しない（他社の広告クリックIDが付いた URL）。
これを新規記事にコピーしてはいけない。

- **afb（t.afi-b.com）の正規リンクのみ使用可**
- 提携が確認できないサービスには、報酬の発生しないリンクを置かない。
  サービス名をテキストで書くに留める
- Netflix には日本のアフィリエイトプログラムが存在しない。リンクで収益化しようとしない

## 内部リンク

- 関連記事へのリンクを**各記事に2本以上**
- 「似ている作品」セクションは内部リンクの主要な置き場
- 該当する既存記事がなければ無理に張らない

## カテゴリとタグ

- カテゴリは既存の12個から選ぶ。新規作成しない
- 記事0件のカテゴリ（学園ラブコメ・恋愛もの / バトルアクション / Youtube動画）を優先的に埋める
- 動画連動記事には `Youtube動画` カテゴリも付ける
