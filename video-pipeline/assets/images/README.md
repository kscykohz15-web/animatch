# 画像フォルダの置き方

台本内に出てくる**キーワード（人物名・地名・組織名など）と同じ名前のフォルダ**を
このディレクトリの直下に作り、その中に対応する画像（jpg/jpeg/png/webp）を入れてください。

```
video-pipeline/assets/images/
  ルーデウス/
    01.jpg
    02.jpg
  ロキシー/
    01.jpg
  地下室/
    01.jpg
  _default/          ← どのキーワードにも一致しなかったシーン用の保険画像（任意）
    01.jpg
```

`plan-scenes.mjs` が台本を空行区切りのシーンに分割し、各シーンの本文にフォルダ名の
文字列が含まれていれば、そのフォルダの画像を自動的に割り当てます。
フォルダ名は台本中の表記（漢字・カタカナ）と一致させてください（部分一致で判定します）。

同じフォルダに複数枚入れておくと、そのキーワードが何度も出てきたときに
順番に別の画像を使うようになります（毎回同じ1枚が使われるのを防ぎます）。

一致するフォルダが無いシーンは `plan-scenes.mjs` 実行後のログに
「候補キーワード」として表示されるので、それを見てフォルダを追加してください。
