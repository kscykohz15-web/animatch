# 演出 ─ 区切りの種類ごとに、エフェクトと効果音を決めます
#
#   書式:  区切り <タブ> 種類 <タブ> 音のファイル <タブ> エフェクト <タブ> 秒数
#
# ここを書きかえて「スライドショー動画にする」をもう一度実行すれば、
# 演出だけ変わります。台本や音声は作り直さなくて大丈夫です。
#
# ■ いまの数字は、本人の動画5本(127分)を mane.py で測って合わせたものです
#
#                        この設定   本人の実測
#   パッと切る(2コマ以内)    66%      62%
#   はっきり溶かす(5コマ以上) 34%      37%
#   一瞬暗くなる             29%      27%
#   効果音が鳴る             66%      65%
#   効果音のずれ           +0.09秒   +0.093秒
#
#   合っているか確かめる:  python 演出あわせ.py
# ─────────────────────────────────────────────

# ■ 区切りの種類（強い順に決まります）
#   章  … 画面表示.txt の章が切り替わるところ
#   。  … 前のセリフが「。」「！」「？」で終わっているところ
#   、  … それ以外の切り替わり
#
# ■ エフェクト
#   暗転        … 一瞬まっ暗になってから、次の絵が出る
#   はさみ      … 前の絵が横に抜けていく。切られたように見える
#   ページめくり … 新しい絵が右から入ってくる。紙をめくるように見える
#   溶ける      … 前の絵がじわっと消える
#   なし        … エフェクトなし（音だけ鳴らしたいとき）
#
# ■ 秒数
#   30コマ/秒なので、0.07秒 = 2コマ。本人はここがいちばん多い（パッと切る）。
#   0.17秒 = 5コマ。本人の3本に1本はこのくらい溶かしている。
#   0.40秒 = 12コマ。章の変わり目だけ、ゆっくり。

区切り	。	カメラ.mp3	暗転	0.17
区切り	、	はさみ.mp3	はさみ	0.07
区切り	章	カードをめくる.mp3	ページめくり	0.40

# 効果音の大きさ。1.0 でそのまま。声の邪魔にならないのは 0.3〜0.5 くらい。
効果音の音量	0.4

# 効果音を、絵の切り替わりから何秒ずらして鳴らすか。
# 本人の動画は +0.093秒（音のほうが少し後）でした。
# 0 にすると切り替わりぴったりで鳴ります。マイナスなら音が先。
効果音のずれ	0.09

# 種類ごとの最低の間隔（秒）。これより近いものは、演出も効果音も入りません。
# 本人は毎回の切り替わりでは鳴らしていない（65%）ので、ここで間引いています。
# 0 か、行ごと消すと間引きません（＝毎回鳴る）。
間隔	。	4.0
間隔	、	4.0


# ─────────────────────────────────────────────
# ■ BGM
#
#   曲は「BGM」フォルダに入っています。別の曲にしたいときは、
#   そこに mp3 / wav / m4a を足して、下の BGM 行の名前を書きかえてください。
#   入れたくないときは、BGM の行を # で消すか「なし」と書きます。
#
#   曲が動画より短ければ、自動でくり返します。長ければ切ります。
#   このとき、
#     ・曲の前後の無音をまず削ります（そのままだと1周ごとに音が切れるため）
#     ・終わりの2秒と、次の頭の2秒を重ねてつなぎます
#   なので、ループ用に作られていない曲でも、つなぎ目が分かりません。
#
#   BGMの音量    … 1.0 でそのまま。声の下で流すなら 0.15〜0.35 くらい。
#                  この曲(-13.2 LUFS)で 0.25 なら、文と文の間で -25 LUFS、
#                  声が出ている間は -35 LUFS くらいになります。
#                  うるさければ 0.15、聞こえなければ 0.35 にしてください。
#   BGMのフェード … 始まりと終わりを、この秒数かけて出し入れします。
#   BGM控えめ    … はい にすると、声が出ている間だけ自動で音量が下がります。
#                  （実測で 0.31倍まで下がります。いいえ なら一定のまま）
# ─────────────────────────────────────────────

BGM	ふおんなきり.mp3
BGMの音量	0.25
BGMのフェード	3
BGM控えめ	はい
