# ─────────────────────────────────────────────
# 演出 ─ 区切りの種類ごとに、エフェクトと効果音を決めます
#
#   書式:  区切り <タブ> 種類 <タブ> 音のファイル <タブ> エフェクト <タブ> 秒数
#
# ここを書きかえて「スライドショー動画にする」をもう一度実行すれば、
# 演出だけ変わります。台本や音声は作り直さなくて大丈夫です。
#
# ■ いまの数字は、本人の動画5本(127分)を mane.py で測って合わせたものです
#
#                        この設定   本人の実測
#   パッと切る(2コマ以内)    66%      62%
#   はっきり溶かす(5コマ以上) 34%      37%
#   一瞬暗くなる             29%      27%
#   効果音が鳴る             66%      65%
#   効果音のずれ           +0.09秒   +0.093秒
#
#   合っているか確かめる:  python 演出あわせ.py
# ─────────────────────────────────────────────

# ■ 区切りの種類（強い順に決まります）
#   章  … 画面表示.txt の章が切り替わるところ
#   。  … 前のセリフが「。」「！」「？」で終わっているところ
#   、  … それ以外の切り替わり
#
# ■ エフェクト
#   暗転        … 一瞬まっ暗になってから、次の絵が出る
#   はさみ      … 前の絵が横に抜けていく。切られたように見える
#   ページめくり … 新しい絵が右から入ってくる。紙をめくるように見える
#   溶ける      … 前の絵がじわっと消える
#   なし        … エフェクトなし（音だけ鳴らしたいとき）
#
# ■ 秒数
#   30コマ/秒なので、0.07秒 = 2コマ。本人はここがいちばん多い（パッと切る）。
#   0.17秒 = 5コマ。本人の3本に1本はこのくらい溶かしている。
#   0.40秒 = 12コマ。章の変わり目だけ、ゆっくり。
#
#   ■「絵の切り替わりが字幕より遅れて見える」とき、見るのはここ（2026-10-06）
#     絵と字幕は**同じコマで切り替わっています**（仕上げ.py の ⑲ がコマを数えて
#     確かめています。29/29・33/33 か所、ずれ 0コマ）。
#     それでも遅れて見えるのは、暗転が「**まっ暗から次の絵が出てくる**」作りで、
#     絵が見えるまでに 0.17秒 = 5コマ かかるからです。
#     字幕はその瞬間に変わっているので、その5コマのあいだ
#     「新しい字幕 ＋ まだ出ていない絵」になります。
#     パッと切りたいときは、下の 0.17 を **0.07** にしてください（2コマ）。
#     0 にすると暗転なし（音だけ）になります。

区切り	。	カメラ.mp3	暗転	0.17
# 「、」の演出は本人の指定でやめました（はさみの音・エフェクトとも）
# 戻すときは下の行の # を外してください
# 区切り	、	はさみ.mp3	はさみ	0.07
区切り	章	カードをめくる.mp3	ページめくり	0.40

# 効果音の大きさ。1.0 でそのまま。声の邪魔にならないのは 0.3〜0.5 くらい。
効果音の音量	0.4

# 効果音を、絵の切り替わりから何秒ずらして鳴らすか。
# 本人の動画は +0.093秒（音のほうが少し後）でした。
# 0 にすると切り替わりぴったりで鳴ります。マイナスなら音が先。
効果音のずれ	0.09

# 種類ごとの最低の間隔（秒）。これより近いものは、演出も効果音も入りません。
間隔	。	4.0

# ■ 全体の最低間隔（秒）── ここがいちばん効きます
#
#   上の「間隔」は種類ごとに数えるので、「。」と「、」が別々に通り、
#   合わせると倍の密度になります。最後にここで全体を間引きます。
#   章（話の変わり目）は必ず残ります。
#
#   0秒 … 174か所 /  3.1秒に1回   ← 多すぎ（本人の指摘）
#   8秒 …  60か所 /  9.0秒に1回
#  12秒 …  46か所 / 11.8秒に1回
#  15秒 …  39か所 / 14.0秒に1回   ← いまの設定。うち13か所は章
#  20秒 …  30か所 / 17.9秒に1回
#  25秒 …  26か所 / 20.8秒に1回   ← ほぼ章だけ
#
#   うるさければ数字を大きく、寂しければ小さくしてください。
#   変えたら  python 演出あわせ.py  で何秒に1回になるか出ます。
演出の間隔	15
