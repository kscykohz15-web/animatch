  横動画 / ショート / X / ブログ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

この文書の使い方
  ・台本を書くとき、まず該当する「型」を開いて、枠に沿って埋める
  ・「導入の型」は、そのまま言葉を差し替えれば使えるようにしてある
  ・数字（尺・文字数）は媒体の仕様と調査に基づく。守る価値がある制約

調べた範囲について正直に書いておく
  ・ブログ（ゆるオタの部屋）は2026-09-24に実際に全記事を読んで確認した。
    4章の内容は推測ではなく実物に基づく
  ・各媒体の仕様（解像度・尺・文字数）は一次情報にあたって確認した
  ・運用の定石は検索結果の要約から拾った。個別の解説記事は読めていない
  ・したがって1〜3章は「こうすれば伸びる」ではなく
    「外さない型」として書いている

  0. 全媒体に共通する考え方
═══════════════════════════════════════════════

■ 我々の武器は「原作を読んでいること」
  アニメ視聴者の大半は原作を読んでいない。
  「アニメでは描かれないが、原作ではこうなっている」は、
  他のどの要素より強い差別化になる。全媒体でここを軸にする。

■ ネタバレの扱いを型にする
  原作の先を話す回は、必ず冒頭で警告する。これは信頼の問題であり、
  同時に「ここから先は特別だ」という強い引きにもなる。
  警告を「注意書き」ではなく「予告」として書くこと。

■ 3か月でリセットされる
  アニメのトレンドは1クールで入れ替わる。放送中の作品には
  新規ファンが流入し続けるので、後発でも波に乗れる。
  放送期間中は「今週の話」に寄せた企画を優先する。

■ 引用元の表記
  画面左上に常時。ブログ・Xでは本文末に。省略しない。
    ©理不尽な孫の手／MFブックス／「無職転生Ⅲ」製作委員会


═══════════════════════════════════════════════
  1. 横動画（YouTube 本編・5〜10分）
═══════════════════════════════════════════════

■ 評価される軸
  視聴維持率。とくに「最初の30秒で何人残ったか」。
  ここが低いと、その後どれだけ良くても伸びない。

■ 全体の骨格

  0:00-0:30  導入      … 何の話か / なぜ見る価値があるか
  0:30-1:00  前提そろえ … 知らない人を置き去りにしない最小限
  1:00-5:00  本題      … 章に分ける。1章 = 20〜40秒
  5:00-5:30  総括      … 図表で「結局こういうこと」を1枚に
  5:30-6:00  締め      … 次回予告 + チャンネル登録

■ 導入の型（4つ。回の性質で選ぶ）

  ① 欠落型 ── 「アニメでは描かれなかった」
     視聴者が知らないことがある、と最初に突きつける。
     例（老デウス回、実際の台本）:
       「今回の動画は、これまでのシリーズとは違います。
        ここから話すのは、アニメでまだ描かれていない、
        原作小説の後半部分の内容です。」
     → 原作先行の回に最適。いまの台本はこの型。

  ② 矛盾型 ── 「おかしいと思いませんでしたか」
     視聴者が薄々感じていた違和感を言語化する。
     例:
       「あの場面、なぜルーデウスは何も言わなかったのか。
        違和感を覚えた人は、正しいです。」

  ③ 数字型 ── 「◯年」「◯人」を冒頭に置く
     具体的な数が、抽象的な問いより強く引く。
     例:
       「一人の男が、五十年かけて世界の構造にたどり着き、
        そして時を遡りました。その五十年を追います。」

  ④ 結論先出し型 ── 答えを最初に言ってしまう
     「なぜそうなるのか」を見に来させる。
     例:
       「第11話に出てきたあの老人は、ルーデウス本人です。
        ただし、我々が見ているのとは別の人生を歩んだ方の。」

  ※ どの型でも「30秒以内に本題に入る」。
    挨拶・自己紹介・チャンネル説明は冒頭に置かない。

■ ネタバレ警告の型（原作先行回のみ）

  導入の直後、15秒以内に収める。長いと離脱する。
    「まだ知りたくない方は、ここで閉じてください。
     それでも構わないという方だけ、この先へどうぞ。」
  → 「注意」ではなく「招待」の語感にする。

■ 章の作り方
  ・1章 = 1つの出来事。20〜40秒。
  ・章タイトルは画面右上に出す（既存の 画面表示.txt の仕組み）
  ・章と章のあいだに「ですが」「その一方で」を置かない。
    区切りは無音（0.4秒）と画面転換で作る。

■ 図表を入れる場所
  ・年表 … 時系列が3つ以上ある回は必ず入れる
  ・分岐図 … 「もしあの時こうしていたら」を扱う回
  ・表 … 失ったもの・人物の対応など、数えられるもの
  ・世界の構造図 … 設定解説の回
  図表は最低8秒、できれば12秒は画面に出す。
  （現状の老デウス回は年表5.7秒・表3.0秒で短すぎる。要修正）

■ タイトルとサムネ
  ・タイトルは「作品名 + 固有名詞 + 問い」
      無職転生 老デウスの五十年｜アニメで描かれない、もう一つの人生
  ・サムネの文字は最大13字。3語以内。
  ・サムネに人物を入れるときは表情が読める大きさで1人だけ。


═══════════════════════════════════════════════
  2. ショート / リール（縦・15〜60秒）
═══════════════════════════════════════════════

■ 仕様
  1080 x 1920 / 最大180秒 / 伸びるのは 15〜30秒
  3媒体（YouTube Shorts・Instagram リール・TikTok）で同一素材が使える
  冒頭のフックだけは媒体ごとに差し替える余地を残す

■ 最初の1〜2秒がすべて
  ここでスワイプされると、その時点で配信が止まる。
  「これから話します」は禁句。いきなり中身から入る。

■ 15秒の型（1つの事実だけを言う）

  0.0-1.5s  フック   … 結論または驚きの事実。文字を大きく出す
  1.5-10s   本体     … なぜそうなのかを1つだけ
  10-14s    落ち     … 余韻。または問いを残す
  14-15s    誘導     … 「本編で全部話しています」

  例:
    [0.0] 第11話の老人は、ルーデウス本人です。
    [1.5] ただし、我々が見ている彼とは別の人生を歩んだ方。
    [4.0] 妻を二人、友を、妹を失って、
    [7.0] 五十年かけてヒトガミを追い続けた末に、
    [10.0] 時を遡って、自分に警告しに来た。
    [14.0] 詳しくは本編で。

■ 30秒の型（流れを見せる）

  0.0-2s    フック
  2-8s      状況     … いつ・誰が・何をした
  8-22s     展開     … 2〜3段。段ごとに画面を替える
  22-27s    結論
  27-30s    誘導

■ 本編からの切り出し方
  ・本編の「章」をそのまま1本にする。章は20〜40秒なので相性が良い
  ・ただし冒頭は書き直す。本編の章頭は文脈を前提にしていて、
    単体では成立しないことが多い
  ・音声は本編のものを流用できる（章の区間を切り出す）が、
    フックの1文だけは録り直す

■ 縦の画面設計
  ・アニメ画像は16:9なので、ぼかし背景で中央に置く（実装済み）
  ・字幕は下から17%。ショートのUIボタンと重ならない位置（実装済み）
  ・上の余白にフックの文字を大きく置くと効く（今後実装）
  ・1画面 = 1文。2文以上を同時に出さない

■ 投稿本数
  本編1本につきショート2〜3本。放送翌日に1本目を出す。

  3. X（旧Twitter）
═══════════════════════════════════════════════

■ 仕様と効くもの
  無料アカウントは280文字（全角半角混在）
  画像・動画つきが優遇される
  公開後30〜60分のエンゲージメント速度が最重要
  リプライでの会話がアカウント評価に効く

■ 3つの型を回す

  ① 単独考察（動画に誘導しない。これが土台）
     140〜200字。1つの事実か視点だけを書く。
     画像1枚（引用元表記を焼き込む）。
     例:
       無職転生の老デウス、原作だと「ロキシーを
       助けられなかった側の人生」を五十年生きている。
       アニメの数分の登場に、それだけの重さが載っている。
       ©理不尽な孫の手／MFブックス／「無職転生Ⅲ」製作委員会

  ② 放送直後の反応（放送当日・30分以内）
     放送中〜直後は検索も流入も跳ねる。
     短く、断定で、1つだけ。
     例:
       今週の無職転生、あの老人の正体を
       「もう一人のルーデウス」と読むと全部つながる。

  ③ 動画の告知（週1〜2回まで。やりすぎると伸びなくなる）
     告知だけの投稿は伸びない。
     本文で内容を出しきって、リンクはリプライに置く。

■ 投稿直後にやること
  ・自分の投稿にリプライで補足を1つぶら下げる（滞在時間が伸びる）
  ・関連する他の投稿に、宣伝でないリプライを数件する
  ・30分は張り付いて、来たリプに返す

■ やらないこと
  ・ハッシュタグの羅列（2個まで）
  ・「拡散希望」
  ・1日5投稿を超える連投


═══════════════════════════════════════════════
  4. ブログ（ゆるオタの部屋 / kasa-yuruotablog.com）
═══════════════════════════════════════════════

■ いまのサイト（2026-09-24 に実際に読んで確認）

  サイト名    ゆるオタの部屋
  ひとこと    ゆるっとアニメを楽しむブログ
  紹介文      10年以上アニメを見続けているアニメ好きが、
              個人的に面白いと思うアニメをご紹介するブログ
  作り        WordPress + AFFINGER + Google AdSense
  カテゴリー  「おすすめアニメ」の1つだけ
  記事数      10本
  最終更新    2025-05-25（4か月以上とまっている）

■ いまある記事は2種類

  ① 作品紹介（8本）
     「作品名」- あらすじや見どころ、見る順番から、
      アニメの動画配信サービス・アプリ(無料・有料)をご紹介！
     ハイキュー / 無能なナナ / 86 / リゼロ / サマータイムレンダ /
     オーバーロード / シュタゲ / メイドインアビス

  ② まとめ（2本）
     本気で号泣した泣けるアニメ20選！
     【一気見】一度見たら止まらなくなる時間が溶ける神アニメ

■ ここが肝心 ── ブログとYouTubeが別の商売になっている

  ブログ    「次に何を見ようか」と探している人に、作品を紹介し
            配信サービスへ送る（AdSense + アフィリエイト）
  YouTube   「もう見た」人に、原作の先や考察を届ける

  読者の層がまったく違う。いまのままでは、
  YouTubeの視聴者がブログに来ても読むものがない。
  逆に、ブログの読者がYouTubeに来ても興味を持てない。

  そして決定的なこと:
    ・無職転生の記事が1本もない
    ・考察記事が1本もない
  3期が放送中で検索需要がいちばん高い作品の受け皿が、無い。

■ 作品紹介の型（既存記事から起こした。8本の実績がある形）

  タイトル
    「作品名 」- あらすじや見どころ、見る順番から、
     アニメの動画配信サービス・アプリ(無料・有料)をご紹介！

  H2  ◯◯が見れる動画配信サービス(アプリ・サブスク)まとめ
    H3  現在配信されているサービス一覧        ← 比較表
  H2  作品情報とあらすじ
    H3  作品情報                              ← 表（放送時期・話数・原作）
    H3  あらすじ
  H2  見どころと個人的おすすめポイント
    H3  （見どころ1）
    H3  （見どころ2）
  H2  「作品名」と似ている作品
    H3  （系統でくくる）
    H3  一気見おすすめのアニメ作品            ← 内部リンク
  H2  アニメ見放題におすすめの動画配信サービス(サブスク)

  目安    本文 3,700字 / 画像 31枚 / 表 4つ
  要点    配信サービスの表を最初に置いている。
          「どこで見られるか」を探しに来た人を最短で満たす形。
          この順番は変えないこと。

■ 考察記事の型（新設。YouTubeの台本から作る）

  いまのブログには無い型。動画の内容をそのまま貼るのではなく、
  検索から入ってくる人に向けて組み直す。

  タイトル  検索語をそのまま含む。32字以内
            例) 無職転生 3期11話の老人は誰？正体と原作でのその後を解説

  導入 200字   結論を先に書く。「この記事で分かること」を3行
  目次         自動生成
  H2 ①  アニメで描かれたこと（何期何話かを明記）
  H2 ②  原作ではどうなっているか（何巻・何章かを明記）
  H2 ③  なぜそうなるのか（考察。推測と事実を書き分ける）
  H2 ④  よくある疑問（Q&A。検索の取りこぼしを拾う）
  まとめ       3〜5行の箇条書き
  末尾         動画の埋め込み + 引用元表記

  ※ 動画は記事の中ほどに置く。冒頭だと離脱する。
  ※ 話し言葉のまま貼らない。検索では評価されない。

■ 検索語から逆算する

  記事は「何を書きたいか」でなく「何を調べている人に届けるか」から
  決める。無職転生で実際に調べられる形:
    無職転生 3期 11話 考察 ／ 無職転生 老人 正体
    無職転生 原作 どこまで  ／ 無職転生 ロキシー 死亡
    無職転生 配信 どこで見れる（← 作品紹介の型で受ける）

■ E-E-A-T（経験・専門性・権威性・信頼性）

  Googleはこれを見る。我々が示せるのは「経験」と「専門性」。
    ・原作の何巻・何章かを明記する
    ・アニメの何期何話かを明記する
    ・推測と事実を書き分ける
      （「原作では〜と描かれています」／「〜と思われます」）
  この3つだけで、感想ブログとの差がつく。

■ まず何をするか（順番に意味がある）

  1. 無職転生の「作品紹介」記事を書く
     既存の型をそのまま使える。3期放送中で検索需要が最大。
     YouTubeの視聴者を受け止める土台にもなる。
  2. カテゴリーに「考察」を足す
  3. 動画1本につき考察記事1本を積む
  4. 作品紹介記事から考察記事へ内部リンクを張る

  ※ 4か月とまっている状態から再開するので、
    まず1本を確実に公開することを優先する。
