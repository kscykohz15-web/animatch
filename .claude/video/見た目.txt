# 全部の動画で共通です。ここを直すと、どの動画も同じ見た目になります。
# 直したら「はじめる.bat」→「4」でもう一度作るだけ。
# 台本も音声も作り直さなくて大丈夫です。
#
# 直す前に見え方を確かめたいときは
#     python make_slideshow.py --preview
# 1枚の PNG（字幕プレビュー.png）ができます。動画は作りません。

# ■ フォント
#   Windows に入っている名前をそのまま書きます。
#   入っていない名前を書くと、黙って別のフォントになってしまうので、
#   作るときに「そのフォントが見つからない」と出たら書きなおしてください。
#   候補: Yu Gothic UI / Meiryo / MS Gothic / BIZ UDPGothic / Noto Sans JP
フォント	Yu Gothic UI

# ■ 字幕の大きさ（画面の短いほうの辺を、いくつで割るか）
#   小さい数字ほど大きい文字です。
#   12 = 1920x1080 で 90px（いまの大きさ）
#   14 = 77px（小さめ） / 10 = 108px（大きめ）
字幕の大きさ	11

# ■ 1行の文字数の上限。これを超えると折り返します（0 なら自動）
#
#   自動のとき、左右の余白は画面の 3%（前は 4%）です。
#   1920x1080・98px で 1行18文字、**2行で36文字**まで入ります。
#
#   ■ 3行目は出ません（本人の指定・2026-10-14）
#
#   > 字幕の改行は二行までにしてください。見にくいです。
#   > その代わり、横幅をもう少し広く使って大丈夫です。
#
#   前は2行に入らないと黙って3行で出していました。いまは
#   行を増やさず、入る大きさまで縮めます（くっつける上限を
#   2行に合わせてあるので、ふだん縮むことはありません）。
字幕の1行	0

# ■ 字幕の行数の上限
字幕の行数	2

# ■ 短い切れ端を、後ろの字幕にくっつける（何文字以下か）
#   絵の切り替わる速さが変わります。「。」で終わるものは動かしません。
#   0 = くっつけない
#   6 = 前の設定
#   8 = いまの設定
#  10 = 本人の指定はこちら。検査（実測15/54・乱数1）で 9.5%% と
#       線の10%%ぎりぎりになるため 8 にしてあります。
#       10 にしても本人の条件（実測54/54）では 4.7%% で変わりません。
#       ここだけ 10 に直して構いません。
#   ※ ここを変えても音とはずれません（長さの合計は1サンプルも変わらない）
#
#   ■ なぜ 10 なのか（本人の指定）
#
#   > このように10文字以下などの、字幕が短すぎるものは他とくっつけてください。
#   > ただし、中途半端にくっつけないように、
#   > 「。」や「、」で字幕の区切りを作ってください。
#
#   くっつける先は「。」か「、」の切れ目しかないので、
#   中途半端な所でくっつくことはありません。
#   「と、」「つまり、」のような短い切れ端が、前後の文と1枚になります。
字幕の最短	8

# ■ 同じ絵を、動画ぜんぶで何回まで使ってよいか
#   同じ風景ばかり流れると、どこの話か分からなくなるので、ここで止めます。
#   3 = 多くても3回まで（いまの設定）
#   候補が足りないときは「上限を超えました」と出るので、
#   そのときは画像を増やすか、画像プランの候補(カンマ区切り)を増やしてください。
同じ絵の上限	3

# ■ 絵をゆっくり動かす（方向は1枚ずつバラバラ）
#
#   止まった絵が並ぶだけだと硬く見えるので、1枚ずつ少しずつ動かします。
#   **向きは「左へ・右へ・上へ・下へ」の4つから、1枚ずつ選びます。**
#   同じ向きが続くとくどいので、直前とはちがう向きになります。
#   番号から決めるので、作り直しても同じ結果になります。
#
#   そのままの大きさだと動かした瞬間に端が切れるので、
#   あらかじめ少し大きく広げてから、画面ぶんを切り出して動かします。
#
#   ■ 速さも距離も、全部の絵・全部の向きで同じです
#
#     1.10倍にすると余りは 横192px・縦108px とちがうので、
#     **小さいほう(縦の108px)を全部の向きの距離にそろえます。**
#     こうすれば、縦のときだけ速く見える、ということがありません。
#
#     動く距離   = min(横の余り, 縦の余り)
#     1秒あたり  = 動く距離 ÷ いちばん長く映る絵の尺
#
#   こうすると、いちばん長い絵でちょうど右端まで行き、
#   それより短い絵は途中で止まります。**どの絵も端が切れません。**
#   短い絵ほど動く量が少ないだけで、速さは変わらないので、
#   見ていて調子が乱れません。
#
#   1.10倍・いちばん長い絵が 4秒なら、距離108px・毎秒 20px。
#
#   動かしたくないときは「画像を動かす いいえ」。
#   章タイトルのカードは、左右で絵と文字を分けているので動かしません。
画像を動かす	はい

# 広げる倍率。大きいほど動かせる幅が増えますが、絵は粗くなります。
#   1.05 = 控えめ / 1.10 = いまの設定 / 1.20 = よく動く
画像の拡大	1.10

# ■ 動きの速さ
#
#   「いちばん長い絵でちょうど右端まで行く速さ」を 1.00 としたときの倍率です。
#   1.00 は本人が見て少し速かったので 0.75 にしています。
#
#   0.50 = かなりゆっくり
#   0.75 = いまの設定（毎秒 20px / 2秒の絵で画面の 2%）
#   1.00 = いちばん長い絵が端ぴったりまで行く
#
#   1.00 を超える値を書いても 1.00 で止めます。
#   超えると、いちばん長い絵で端が切れてしまうためです。
動きの速さ	0.75

# ■ 書き出しの速さ（x264のプリセット）
#   スライドショーは動きがほとんど無いので、速くしても見た目はほぼ変わりません。
#   veryfast … いちばん速い。ファイルは少し大きくなります
#   faster   … いまの設定。速さと大きさの釣り合いが良い
#   medium   … 前の設定。いちばん遅い（速さの割に得るものが少ない）
書き出しの速さ	faster

# ■ 色（RRGGBB）。ふちは字のまわりの黒い線です。
字幕の色	FFFFFF
字幕のふち色	000000
# ふちの太さ（文字の大きさに対する割合）。0.115 = いまの太さ
字幕のふち	0.115

# ■ 左上の引用（画面の短いほうの辺を、いくつで割るか）
引用の大きさ	38
引用の色	FFFFFF

# ■ 右上の章タイトル
章の大きさ	19
章の色	FFFFFF
