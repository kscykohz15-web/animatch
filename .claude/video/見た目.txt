# ■ フォント
#   Windows に入っている名前をそのまま書きます。
#   入っていない名前を書くと、黙って別のフォントになってしまうので、
#   作るときに「そのフォントが見つからない」と出たら書きなおしてください。
#   候補: Yu Gothic UI / Meiryo / MS Gothic / BIZ UDPGothic / Noto Sans JP
フォント	Yu Gothic UI

# ■ 字幕の大きさ（画面の短いほうの辺を、いくつで割るか）
#   小さい数字ほど大きい文字です。
#   12 = 1920x1080 で 90px（いまの大きさ）
#   14 = 77px（小さめ） / 10 = 108px（大きめ）
字幕の大きさ	12

# ■ 1行の文字数の上限。これを超えると折り返します（0 なら自動）
字幕の1行	0

# ■ 字幕の行数の上限
字幕の行数	2

# ■ 短い切れ端を、後ろの字幕にくっつける（何文字以下か）
#   絵の切り替わる速さが変わります。「。」で終わるものは動かしません。
#   0 = くっつけない（いまの設定。切り替わりは 2.01秒に1回）
#   6 = 本人の動画と同じ速さ（2.17秒に1回。本人の実測は 2.20秒）
#   8 = 少しゆっくり（2.32秒に1回）
#   ※ ここを変えても音とはずれません（長さの合計は1サンプルも変わらない）
字幕の最短	0

# ■ 色（RRGGBB）。ふちは字のまわりの黒い線です。
字幕の色	FFFFFF
字幕のふち色	000000
# ふちの太さ（文字の大きさに対する割合）。0.115 = いまの太さ
字幕のふち	0.115

# ■ 左上の引用（画面の短いほうの辺を、いくつで割るか）
引用の大きさ	38
引用の色	FFFFFF

# ■ 右上の章タイトル
章の大きさ	24
章の色	FFFFFF
