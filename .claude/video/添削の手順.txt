 添削の手順 ── 台本を出す前に、毎回2周する
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

本人の指定（2026-11-08）:
  「今後はあなたの方でも2回は事実との乖離や間違いがないのか毎回添削する」

2周は「同じものを2回見る」ではない。**別の物を見る。**


━━ 1周目 ── 機械（仕上げ.py ㉕ が自動でかける）━━━━━━━━━━━━

  python 仕上げ.py        ← これだけで下の3つが走る

  ① 放送情報検査.py  第一期の 年・季・話数・制作・原作・掲載誌・なろう
                     （元は 放送情報.txt ＝ AniList とウィキペディア）
  ② 事実検査.py      続編の数・劇場版の有無・「放送」と「公開」・
                     並び順・つなぎの年・「いちばん新しい」の限定
                     （元は 続編情報.txt ＝ AniList の関係をたどったもの）
  ③ 作品メモ検査.py  **調べて確かめた中身**（作品メモ.txt）との突き合わせ
                     ・「言わない」欄の禁句が台本に出たら落ちる
                     ・主人公・ヒロインの名前が段落に無ければ注意
  ④ 添削検査.py      本人の添削4つ・立場・100字・段落109本・言いまちがい

  新しい作品を足したときは、先に元を引き直す:
      python3 -I .claude/video/放送情報を引く.py
      python3 -I .claude/video/掲載誌を引く.py
      python3 -I .claude/video/なろうを引く.py
      python3 -I .claude/video/続編を引く.py

  **検査が鳴ったら、まず検査を疑う。** つなぎの年の検査は偽の落ちを3件出し、
  台本のほうが正しかった（メモリ 101-9）。


━━ 2周目 ── 目で読む（機械では止まらない）━━━━━━━━━━━━━━━

本人が見つけた11件のうち、**機械で止められたのは放送年と社名と言い方だけ。**
人物の立場とあらすじの中身は止まらない。だから1作品ずつ読む。

作品ごとに、あらすじの段落を出して読む:

**まず 作品メモ.txt を見る。** 調べた作品はもう控えてあるので、引き直さない。
控えが無い作品だけ記事を引き、**読んだらその場で1行足す**（記憶で書かない）。

  python3 -I - <<'PY'
  import io, re
  TS = u"最初にご紹介する作品は|続いての作品は|続く作品は|続いては|最後にご紹介する作品は"
  d = [x.strip() for x in io.open(u"<台本>", encoding="utf-8-sig")
       .read().replace(u"\r\n", u"\n").split(u"\n") if x.strip()]
  for i, x in enumerate(d):
      m = re.search(u"(?:%s)、?(.+)$" % TS, x)
      if m and i + 2 < len(d):
          print(u"\n【%s】 %s" % (m.group(1).strip(), d[i + 2]))
  PY

読むときに見るのは、この5つ:

  1. **その人の立場**は合っているか
     （五条新菜は衣装ではなく**頭師**／ルルーシュは亡国ではなく**帝国**の元皇子／
       公安9課の課長は**荒巻**で素子は実働部隊の隊長）
  2. **誰が何をしているか**が入れ替わっていないか
     （ダンダダンは信じているものが**逆**だった。モモ＝幽霊／オカルン＝宇宙人）
  3. **「〜だけ」「誰も」「唯一」**のような言い切りが本当か
     （古見さんは只野と**だけ**ではない／幻想殺しは**誰にも**知られていなくはない）
  4. **物の名前**が合っているか
     （少女終末旅行は装甲車ではなく**半装軌車**／GRIDMAN は電器屋ではなく**ジャンク屋**）
  5. **数字**は出典まで当たったか
     （推しの子の第1話は**90分**。拡大枠の発表がそう。本編の実尺は約84分）

直したら、**作品メモ.txt の「言わない」欄にその言い方を足す。**
同じ間違いが次の回に黙って戻らないための歯止めで、ここがこの控えの心臓。

確かめ方は ja.wikipedia の `?action=raw`（urllib は 403 なので curl）:

  curl -s --retry 3 -A "research-script" \
    "https://ja.wikipedia.org/wiki/$(python3 -c 'import urllib.parse,sys;print(urllib.parse.quote(sys.argv[1]))' '作品名')?action=raw"

**直す前に引く。** 平家物語の「主人公の琵琶法師、びわ」は直しかけたが、
ウィキペディア自身が「琵琶法師の少女『びわ』が主人公」と書いていた。
