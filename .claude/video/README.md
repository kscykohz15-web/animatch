# 動画制作の設定と、確かめる道具

**ここは控えです。** ふだん動かすのは作業場所（scratchpad）側。
作業場所は消えることがあるので、消えたらここから戻します。

```
cp .claude/video/* <scratchpad>/video/
cp 仕上げ.py        <scratchpad>/
```

`make_slideshow.py` などの本体はここには置いていません。
**掲示板(board.html)の `<script id="py-*">` に入っている**ので、そこから戻します。
`board.src.html` `build.py` `sync_py.py` も作業場所側にしかありません。

## 設定（全動画で共通。パックにそのまま入ります）

| ファイル | 中身 |
|---|---|
| `見た目.txt` | フォント・字幕の大きさ・色・ふち・引用と章の大きさ |
| `演出.txt` | 切り替え効果と効果音、BGM |
| `タグ一覧.txt` | `#指定` に使ってよい言葉。ここに無い綴りは黙って外れる |
| `話数マップ.txt` | どの話数に何があるか |
| `人物ルール.txt` | 絵を見直さずに人物名の判定を変えるところ |
| `読み辞書.txt` | 読み上げの読み方 |
| `当て方.txt` | 言葉 → 絵 の対応表。厚くするほど次の台本にも効く |

## 動画ごと

| ファイル | 中身 |
|---|---|
| `画面表示_○○.txt` | 左上の引用と、右上の章タイトル |
| `画像プラン_○○.txt` | 字幕1枚ずつに当てる絵。章ごとに `@@話数` を切り替える |

## 確かめる道具

| 道具 | すること |
|---|---|
| `../../仕上げ.py` | **これを通さずに掲示板へ出さない。** 下の全部をまとめて回す |
| `全部しらべる.py` | 章のキーワードが本当に字幕に当たるか（8本ぶん） |
| `shou_check.py` | 上の1本ぶん |
| `plan_check.py` | タグの綴り・話数フォルダ・死んだキーワード・当たる割合 |
| `プラン全部作る.py` | 画像プランを7本ぶん作り直す。**章ごとの `@@話数` はここ** |
| `プラン下書き.py` | その1本ぶん |
| `ずれ検査.py` | 字幕と声のずれを、材料を作って実測する |
| `絵と字幕の検査.py` | 絵と字幕が同じコマで切り替わるか、コマを数えて実証する |
| `直す検査.py` | 数字ひとつで絵を入れ替える仕組みが働くか |
| `文脈検査.py` | **本人の直し(29〜37番)を、機械だけで再現できるか**（本物の字幕で） |
| `人物ルール検査.py` | 人物ルールと「やられ顔」の言葉が、本当にあるタグか |
| `パック検査.py` | 道具が4か所ぜんぶ（置き場所・同期・ZIP・Prepare）に入っているか |

台本を書きかえたら `python プラン全部作る.py`、最後に `python 仕上げ.py`。
