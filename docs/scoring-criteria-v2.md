## 1. 採点6項目と配点

| DBカラム | 項目 | 重み | 配点 |
|---|---|---|---|
| `story_10` | シナリオ | **3.75** | **32.5%** |
| `emotion_10` | 心・感情 | 2.5 | 21.6% |
| `world_10` | 世界観 | 2.0 | 17.3% |
| `animation_10` | 作画 | 1.0 | 8.7% |
| `tempo_10` | テンポ | 1.0 | 8.7% |
| `music_10` | 音楽 | 1.0 | 8.7% |
| `cute_10` | キャラの可愛さ | **0.3** | **2.6%** |

標準の項目（作画・テンポ・音楽）を1.0とする。**シナリオはその3.75倍で最重要**、
**キャラの可愛さは0.3で最も軽い**。採点そのものは全項目同じ0.1刻み・同じ厳しさで
独立して付け、総合点への効き方だけを重みで変える。

```
総合点(100) = (story*3.75 + animation*1.0 + world*2.0 + emotion*2.5 + tempo*1.0 + music*1.0 + cute*0.3) / 11.55 * 10
            = 7項目の重み付き平均（0〜10） × 10
```

`app/page.tsx` の `OVERALL_WEIGHTS` も同じ配分（3.75 / 1.0 / 2.0 / 2.5 / 1.0 / 1.0 / 0.3）。

重みの履歴：シナリオ 2.5 → 3.75（1.5倍）、キャラの可愛さ 0.5 → 0.3（0.6倍）。

> **可愛さの点数について**：オーナー本人はこの項目をまだ採点していないため、本人評価17作品を含め
> 全作品の `cute_10` はAI推定値。本人が付けた6項目の点数は一切変更していない。

## 2. 数値ルール

- 範囲は **0.1〜10.0**、小数第1位まで（0.1刻み）。
- 型は `numeric(3,1)`。
- **未評価は NULL**。`0` は未評価値として使わない（0点という評価も付けない）。
- **7項目すべてが埋まった行だけ**を正式スコアとして扱う。1項目でも採点できなければ、その行は書き込まずNULLのまま残す。
- AIの自信度が低い（`confidence < MIN_CONFIDENCE`）場合も書き込まない。

## 3. 厳しめ採点の指針

従来のAI採点は「全体的に高すぎる」「点がばらけない」という問題があった（旧フルスキャン時の `story_10` 分布は 6点 1553件 / 7点 1181件 に集中）。v2では以下を守る。

- 何でもかんでも10点にしない。**10.0 はほぼ使わない**。
- 9.5以上は歴史的傑作の、その作品を代表する一点のみ。
- 7.0は「良い」。8.5以上で初めて「明確に神」。
- **オリジナリティ**が評価の核。既視感・テンプレの強い作品は6点台以下に落とす。
- **世間的評価**（人気・話題性・評価の定着）も材料にする。ただし人気＝高得点ではない。
- 6項目は独立。作品全体が好きでも全項目を引き上げない。1作品内で項目差を付ける（最高項目と最低項目の差は原則1.5以上）。

## 4. 項目別の見方

- **シナリオ (story)**: 構成・伏線回収・結末の畳み方。設定の面白さではなく「話として組めているか」。打ち切り/未完/原作途中で終わる構成は減点。
- **作画 (animation)**: 映像・アニメーションの質と演出。古い作品は時代性を考慮（当時として高品質なら相応に評価、ただし現在の最高峰と同点にはしない）。作画崩壊歴は減点。
- **世界観 (world)**: 設定の独自性・唯一無二さ・広がり・その作品ならではの魅力。シナリオと独立して高くなり得る（唯一無二なら9点台）。よくある異世界/宇宙/学園は6点台。
- **心・感情 (emotion)**: 感動、感情移入、心を揺さぶる力、心に刺さる描写。泣ける・刺される・勇気をもらえるが強ければ9点台。
- **テンポ (tempo)**: 速さではなく「ダレない / 退屈しない / 視聴ストレスがない」。中だるみ・引き伸ばしは減点。遅いテンポが作品に合っていれば減点しない。
- **音楽 (music)**: 曲単体の良さではなく、劇伴やOP/EDが**感情と没入をどれだけ増幅しているか**。良いBGMがある程度では7.0前後に留める。

## 5. アンカー（採点感覚の基準）

`scripts/lib/score-anchors-v2.mjs` に2種類ある。混同しないこと。

1. **`USER_RATINGS_17`（本人評価・17作品）**
   ユーザー本人が付けた点数とコメント。**整数・旧スケール**。
   AIが作った評価や一般的な作品評と混同してはいけない。
   役割は「**項目間・作品間の相対感覚の正解**」。
2. **`STRICT_SCALE_ANCHORS`（新基準アンカー・0.1刻み）**
   先頭の進撃の巨人 `9.5 / 9.0 / 8.1 / 8.0 / 7.5 / 7.0` は**ユーザー本人が新基準として提示した参考点数**。
   それ以降は本人の考え方に沿ってAIが推定した較正用アンカー（本人評価ではない）。
   役割は「**数値スケールの正解**」。

旧→新のスケール感：本人評価の進撃の巨人（シナリオ10）は新基準では9.5。
相対順位は本人評価に合わせ、数値の絶対値は新基準アンカーに合わせる。

## 6. 本人評価の保護

- `anime_works.rating_source` が `'user'` の行はAI採点で上書きしない（`LOCK_USER_RATED=false` で解除可）。
- 本人評価17作品の投入は `scripts/seed-user-ratings-v2.mjs`。

## 8. 933作品の採点データ（2026-11-05）

ユーザー提供のExcel（`アニメ一覧` シート、2001〜2024年の933作品）を、この基準で全件採点した。

- 成果物: `data/animatch_評価済み.xlsx`
  - `アニメ一覧` シート（本人評価の作品は太字）
    - E/F: 私的・公的
    - G〜L: シナリオ / 作画 / 世界観 / 心・感情 / テンポ / 音楽（各1列）
    - M: 合計(100点) ＝ 6項目の加重合計。私的はこれを10点換算した値
    - N: 原作（漫画 / ラノベ / Web小説 / Webマンガ / 小説 / ゲーム / ソシャゲ / オリジナル / 特撮）
    - O: ジャンル（主ジャンルを1つ。異世界・バトル・コメディ・ラブコメ ほか全27種）
    - 旧「ジャンル」フラグ見出し（ラブコメ/ハーレム/ミステリーの空列）は1列のジャンル列に置き換えた
  - `採点v2` シート: 原作・ジャンル・6項目・私的(総合)・合計(100点)・公的・項目差・評価元・根拠
  - `採点基準` シート: この基準と、原作・ジャンルの区分一覧
- 機械可読データ: `data/scores-v2.csv`（`seen` 列で視聴済み/未視聴を区別）
- 閲覧用ページ: `data/score-viewer.html`（スマホ・PC両対応）
  - 一覧（カード）とランキング（作品名だけの行、タップで6項目の内訳が開く）の2モード
  - 検索／原作・ジャンル・年代をチップで**複数選択**（グループ内はOR、グループ間はAND）／本人評価のみ／12種類の並べ替え
  - 表示モードと絞り込み条件は端末内（localStorage）に保存
  - 生成: `node scripts/build-score-viewer.mjs`（CSVを読み、`scripts/templates/score-viewer.html` に差し込む）
  - 点数を更新したらCSVを作り直して再生成すればページも最新になる
- DBへの投入: `node scripts/seed-scores-from-csv.mjs`（`DRY_RUN=true` で確認）

### 未視聴作品の追加（2026-11-14）

オーナーのリストに無かった作品80本を同じ基準で採点して追加した。合計1,013作品。

選定ルール：
- **劇場作品は入れない**（TVシリーズ・OVAシリーズのみ）
- **非深夜の長編は、誰でも知っているものだけ**：ONE PIECE / ドラゴンボールZ / 名探偵コナン / ポケットモンスター / SLAM DUNK / 美少女戦士セーラームーン / 機動戦士ガンダム / 新世紀エヴァンゲリオン の8本
- それ以外は**深夜アニメ中心**に、ネットでの評価が高い作品から選ぶ
- 既視聴シリーズの続編（ノラガミARAGOTO など）は、本人が観たか判別できないため入れない

内訳は 1970〜90年代13本 / 2000年代19本 / 2010年代28本 / 2020年代20本。
未視聴80本は全項目がAI評価（本人評価ではない）。分布は中央値6.6。

区別の仕方：CSVは `seen` 列（seen / unseen）、Excelは「視聴」列＋行の薄いオレンジ塗り、
閲覧ページはオレンジの「未視聴」バッジと左の縦線＋視聴状態での絞り込み。

### 内訳

| 評価元 | 件数 | 内容 |
|---|---|---|
| 本人評価 | 17 | オーナー本人が付けた点数（進撃の巨人のみ本人提示の新基準値）。キャラの可愛さのみAI推定 |

### 列の意味

- **私的(総合)**: 6項目の加重平均を10点満点に換算した値（= 総合100点 ÷ 10）。本人の好み基準。
- **公的**: 世間一般での評価・話題性の推定値。人気が高いだけでは高得点にしない。

### 分布（933作品・私的／7項目・現行配点）
