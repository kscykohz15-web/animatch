# 選び直しを学ぶ仕組み（案 A）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 本人がスマホで選び直した絵を掲示板にためて、次に作る動画で「字幕に出てくる人が写っている絵」を先に当て、当たり率を見せる。

**Architecture:** 掲示板（board.src.html の JS）が「修正を決定」のたびに `manabi/<印>` へ足し、制作パックに全動画ぶんを `99_確認不要/その他/本人の選び.txt` として入れる。make_slideshow.py が台本から人の名前を読み、本人の選び.txt から「絵に写っている人」を覚え、assign_images の ④（となりの同じ絵を避ける段）の直前で当て直す。スマホ用の目録（ichiran.json）に字幕ごとの人と覚えた人を書き、掲示板が候補の並びと印に使う。

**Tech Stack:** Python 3（make_slideshow.py・標準ライブラリのみ）、掲示板の JS（ES5・"use strict"）、PowerShell（menu.ps1 は board.src.html の buildMenuPs1 の文字列）、テストは node の Playwright と Python。

**Spec:** `docs/superpowers/specs/2026-11-21-選び直しを学ぶ-design.md`

## Global Constraints

- 返事・コメント・ログの文言は日本語（CLAUDE.md）
- 別の作品の絵は出さない（覚えるのも使うのも作品フォルダの中だけ）
- 手で選んだ絵（差し替え.txt）・作品の頭の公式画像（daiji）・画像プランに手で書いた絵（tebiki）・はじめに/おわりに（＊全作品）には触らない
- 無職転生の回（`OSUSUME[0]` が偽）は何も変えない
- 控え（db）から読んだ物に書き込まない（`dbody` の写しを使う）
- パックに足す物は ZIP（exportAllPack）と Prepare の2か所（CLAUDE.md）
- お金のかかるものは使わない（API なし）
- PACK_VERSION を上げ、メモリ・CLAUDE.md に節を足す。仕上げ.py が全部通ってから出す

## Review Focus

- 同じ字幕を何度も決め直す（A→B→いまの絵に戻す）: 最後の決定だけが残ること → Task 2 のテスト
- 名前が台本から取れない作品（あらすじに「主人公、名前」の形が無い）: 「主人公」「ヒロイン」の言葉どうしで合わせ、落ちないこと → Task 1 のテスト
- 短い呼び名が別の言葉の一部になる（「恵」が「恵まれる」に入る等）: その章の台本に2回以上・名前として出るものだけ使う → Task 1 のテスト
- 覚えた絵が動画の別の所でもう使われている: 同じ絵を重ねず、使っていない絵を先にする（tsukai を見る） → Task 3 のテスト
- 本人の選び.txt が無い・空・壊れた行: 今までどおりの当て方で最後まで動くこと → Task 3 のテスト
