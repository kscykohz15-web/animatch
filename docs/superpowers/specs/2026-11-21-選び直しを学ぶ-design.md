# 選び直しを学ぶ仕組み（案 A）の設計 ─ 2026-11-21

## なぜ（本人の言葉）

> この変更を覚えていてもらいたくて、変更した内容を蓄積して、データとして解析しどんどんあなたの画像割り当て精度を高めて欲しいです。

本人がスマホで選び直した 118 か所（ラブコメ20選）を見比べると、替えた先はほぼ「その字幕に出てくる人が写っている絵」。
選び直した割合は 名前の出る字幕 67%・立場の言葉（主人公・ヒロイン等）52%・人が出ない字幕 29%。
おすすめ紹介の絵には「誰が写っているか」の説明が無く、機械は作品フォルダの絵をばらけた順に当てているだけ。

## 目的・目的でないこと

- 目的: 本人の選び直しを**消さずにため**、次に作る動画（同じ動画の作り直し・同じ作品が出る別の回）で
  **名前の出る字幕にその人の絵を先に当てる**。どれだけ当たるようになったかを**数で見せる**
- 目的でない: 選んだことの無い絵に名前を付けること（案 B・C。あとから足せる形にはしておく）
- してはいけない: 別の作品の絵を出す・本人が手で選んだ絵（差し替え.txt）を上書きする・無職転生の回を変える

## ためる（掲示板）

- 「修正を決定」のたびに、掲示板の控え `manabi/<動画の印>` に足す（**上書きしない・動画をまたいでためる**）
  - 1行 = 作品フォルダ・選んだ絵・機械が当てていた絵・字幕の文・決めた日時
  - 「いまの絵に戻す」で決めた所は、その字幕の行を消す（機械の絵で良いと決めた）
  - 決定ごとに「字幕の数・選び直した数」も残す（当たり率の推移用）
- 制作パックを落とすと、**全部の動画ぶん**が `99_確認不要/その他/本人の選び.txt` に入る（ZIP と Prepare の2か所）

## 使う（パソコンの道具・make_slideshow）

- 名前: その回の台本のあらすじから読む（「主人公、高須竜児と」「ヒロインの喜多川海夢から」の形・ラブコメ20選は20作品とも取れた）。
  短い呼び方（竜児・海夢・麻衣先輩の「麻衣」）は、同じ章の台本に出てくる部分だけ使う
- 字幕ごとの「出てくる人」: 名前があれば名前。無ければ「主人公」「ヒロイン」「二人」をその作品の名前に読みかえる
- 絵ごとの「写っている人」: 本人の選び.txt の字幕の文から同じやり方で読む（その作品の中だけ）
- 当て方（作品フォルダの絵を当てたあと・差し替えの前）:
  1. 出てくる人が**全員写っている**と分かった絵（まだ使っていないもの）を先に
  2. 次に一部が写っている絵
  3. 人が出ない字幕は、本人が選んだことのある絵（＝使える絵）を、外された絵より先に
  4. 外されたことがあり一度も選ばれていない絵は、ほかに無いときだけ
  - となりの字幕と同じ絵・同じ場面（名前が隣のコマ）は続けない（今の決まりのまま）
  - 本人が手で選んだ絵（差し替え.txt）・作品の頭の公式画像・画像プランに手で書いた絵には触らない
- ログに「本人の選びから: ○か所を名前の合う絵に替えました（覚えた絵 ○枚）」

## スマホの画面

- 候補の並びを、その字幕に出てくる人が写っていると分かった絵から先に。印「覚えた: 高須竜児」
- スマホ用の一覧（ichiran.json）に、字幕ごとの「出てくる人」と、絵ごとの「覚えた人」を道具が書く（掲示板は読むだけ）

## 測る

- 掲示板の「スマホで見る・絵を選ぶ」に、動画ごとの **当たり率（選び直さずに済んだ字幕の割合）** を作った順に並べる
  （ラブコメ20選のいまは 290 字幕中 172 = 59%）

## 見張り

- 新しいテスト（仕上げ.py ㊱）: ためる → パックに入る → 道具が名前の合う絵に替える → 手で選んだ絵・公式画像は触らない →
  別の作品の絵は出ない → スマホの並びと印 → 当たり率
- 本人の 118 か所で、名前の読み取りと「覚えた人」が正しいかを数で確かめる

## 私（Claude）が決めたこと

- 名前は作品メモではなく台本から読む（全作品で取れるため）。作品メモは足りない所の予備にしない（増やすと二重になる）
- 外された絵は「使わない」ではなく「後回し」（同じ絵が別の字幕には合うことがあるため）
- 覚えるのは作品フォルダの中だけ（別の作品へは持ち出さない）
- 使うのは1作品の章だけ。はじめに・おわりに（＊全作品・作品を1枚ずつ順に）と作品の頭の1文は今の決まりのまま
- 名前が台本から取れない作品でも、「主人公」「ヒロイン」の言葉どうしで合わせる（名前が分かれば名前に読みかえる）
